Exam day

Exam-Day Playbook

How to turn what you studied into marks: answer structure, command words, diagrams and the comparison questions to expect.

Writing answers that score

2 marks

  • One-line definition in textbook words
  • Plus one example or key feature
  • 2–3 lines total. Don't write an essay.

4–6 marks

  • Definition
  • A small diagram or a table, if one exists
  • 4–6 points, each with a bold keyword and one explaining line
  • One example

8–10 marks

  • Definition / introduction (2 lines)
  • Neat labelled diagram, drawn first
  • Explain each box or phase under its own sub-heading
  • Advantages and disadvantages, or a comparison
  • When to use it + a case-study example
  • One-line conclusion

Examiners mark keywords, structure and diagrams. Underline the keywords (the highlighted phrases in this guide), number your points, and leave space between them.

Diagram rules

  1. Draw first, write after. The diagram tells you what to explain, and it scores even if time runs out.
  2. Label every box and arrow using the textbook's names (for example "Requirements definition", not "Req").
  3. Give it a caption: Fig: The waterfall model.
  4. Use boxes for activities, arrows for flow, and dashed arrows for feedback or iteration.
  5. Keep it big and clean. Half a page is fine for a 10-mark question.

Command words decoded

If the question says……it wants
Define / What isThe exact definition, plus one example. Short.
List / EnumerateThe complete list, numbered. One line each is enough.
Explain / DescribeDefinition + points with explanation + diagram if one exists + example.
With a neat diagramThe diagram carries a large share of the marks. Draw it carefully and explain every part.
Differentiate / Compare / DistinguishA table with a "Basis" column and 5–7 rows. Add one line each of "use A when…, use B when…".
Discuss / JustifyPoints for and against, then your conclusion with a reason.
Apply to / For the given case studyName the system in every point. Generic answers lose marks here.

When a question names a system (insulin pump, Mentcare, weather station, iLearn, or something new like a library or ATM system), connect every point to it: "Because the insulin pump is safety-critical, …". If the system is new, pick the textbook system it most resembles and reuse that reasoning.
